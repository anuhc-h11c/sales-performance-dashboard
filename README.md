# sales-performance-dashboard
Sales analysis dashboard using Power BI

Project Overview

This project contains a two-page Power BI report created to practise sales data analysis and data visualization.

Tools Used

- Microsoft Power BI
- Interactive charts and KPI cards
- Tables and slicers

Dashboard Features

- Sales performance overview
- Product and country comparisons
- Salesperson performance analysis
- Interactive filtering and visualizations

Project Status
Completed practice project.
